# HabitFit - Fitness for Beginners

HabitFit is a static, SEO-ready beginner fitness website built from scratch.

## Pages

- `index.html` - responsive homepage with hero, roadmap, workout cards, nutrition section, FAQ, structured data, and an interactive habit tracker.
- `beginner-workout-plan.html` - 4-week beginner training plan.
- `at-home-workouts.html` - no-equipment beginner workouts and mobility reset.
- `nutrition-for-beginners.html` - simple beginner nutrition guidance.
- `robots.txt` and `sitemap.xml` - crawl and indexing support.

## Deployment

This project is ready for GitHub Pages. In the repository settings, enable Pages from the `main` branch and root folder.

Expected Pages URL:

`https://ayushmishra-02.github.io/HabitFit/`
