# HabitFit WordPress Theme

This is a separate WordPress theme branch; the main branch and current Vercel deployment are not changed.

## Install
1. Download this branch as ZIP: https://github.com/AyushMishra-02/HabitFit/archive/refs/heads/wordpress-theme.zip
2. WordPress Dashboard → Appearance → Themes → Add New → Upload Theme.
3. Upload the ZIP, install, and activate.
4. Create these four pages in WordPress with these exact slugs: Home (home), Beginner Workout Plan (beginner-workout-plan), At-Home Workouts (at-home-workouts), Nutrition for Beginners (nutrition-for-beginners). Add the workout/nutrition content from the project, then set Home as the static front page under Settings → Reading.
5. Settings → Permalinks → Post name → Save.
6. Test the homepage, guide pages, dark mode, habit tracker, and navigation.

The VPS is not part of this step. Keep the Vercel site as a backup. Before public deployment, verify canonical URLs, robots.txt, sitemap, HTTPS, and backups.
